# Hynix Interview Lab

2.5D 패키징과 메모리의 기초부터 패키지 CAE·HBM 심층 면접까지 준비하는 한국어 학습 웹앱입니다.

- 공통 기초 2개, 2.5D 패키징 8개, 메모리 7개, HBM 통합 이해 1개: 총 18개 학습 단원
- 개념 설명·구조 그림·수식·단원별 퀴즈 및 해설
- 10개 질문 트리: 5단계 질문 50개 + 답변에 따른 분기 질문 20개
- 성과 근거 카드 8개와 답변 메모, 복습 태그, 자가 평가
- 60초·3분 답변 타이머, 전체 검색
- 공식 발표 기반 산업 카드 6개. 자료 확인 기준 2026-10-17
- 브라우저 로컬 저장, JSON 백업·복원

## 실행

빌드나 의존성 설치가 필요 없는 정적 HTML/CSS/JavaScript 앱입니다.

```sh
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. GitHub Pages 하위 경로에서도 동작하도록 상대 경로와 해시 라우팅을 사용합니다.

## 콘텐츠 검증

```sh
node verify-content.mjs
node --check assets/app.js
```

## 데이터와 출처

개인 답변·진도·성과 근거는 `localStorage`의 `hynix-interview-lab-v1`에 저장됩니다. 서버 전송이나 기기 간 자동 동기화는 없습니다. 브라우저를 바꾸기 전 복습 노트에서 백업 파일을 내보내세요. 백업을 불러오면 현재 기록을 교체합니다.

지원서 PDF 원본, 이름, 연락처, 주소는 포함하지 않습니다. 경력 기반 질문에서 확인되지 않은 모델·계수·시험 조건은 사용자가 직접 작성하도록 구성했습니다. 실제 수행 경험과 새로 주어진 가정 상황을 구분합니다.

학습 단원과 산업 카드에는 공식 기술 자료·발표의 링크를 제공합니다. 제품 상태는 발표·샘플·데모·양산을 구분하며, 시나리오와 직무 관점은 해석으로 표시합니다. 면접 전 최신 발표를 확인하세요.

이 프로젝트는 개인 학습용이며 SK하이닉스의 공식 채용 서비스가 아닙니다.
