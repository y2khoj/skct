# Hynix Interview Lab

2.5D 패키징과 메모리의 기초부터 패키지 CAE·HBM 심층 면접까지 준비하는 한국어 학습 웹앱입니다.

- 공통 기초 2개, 2.5D 패키징 16개, 메모리 7개, HBM 통합 이해 1개: 총 26개 학습 단원
- 세 시작 경로: 메모리 구조부터 / 내 실적부터 점검 / 패키징 공정부터. 선택한 경로의 이전·다음 단계와 복귀 동선을 유지합니다.
- 개념 설명·주제별 구조 그림·수식·단원별 퀴즈 및 해설
- PackagingBook 기반 공정 지식 8개 단원, 와이어 본딩·플립칩·HBM/2.5D의 3개 공정 지도
- 두께·피치/전류·선별 조건을 직접 바꾸는 계산기 3개. 모델의 가정과 적용 범위를 함께 표시
- 여덟 심층 사례: Warpage, CCSB, BLR 수명, 서브모델, Roofline, 소표본 회귀, KGD 선별·적층 수율, 미세 피치·전류 밀도
- 각 사례에 가상 데이터·완결 풀이·조건 변경 문제·선택지별 해설·관측 분기
- HBM·2.5D 신규 구조의 최종 판단 메모
- 14개 질문 트리: 5단계 질문 70개 + 답변에 따른 분기 질문 28개
- 질문별 사고 구조·기술 예시·흔한 오답·조건별 꼬리질문 코칭
- 구성방정식·젖음 에너지·열전달 지표·벽면 처리의 단계별 필수 원리 해설 4개
- 성과 근거 카드 8개와 답변 메모, 복습 태그, 관찰 가능한 0·1·2점 자가 평가
- 읽음·개념 문항 정답·답변 작성·자가검토를 별도 표시, 미평가와 명시적 0점 구분
- 답변을 수정하면 기존 점수를 현재 답변의 평가로 표시하지 않고 재검토를 요구합니다.
- 60초·3분 답변 타이머, 전체 검색
- 공식 발표 기반 산업 카드 6개. 자료 확인 기준 2026-10-17
- 브라우저 로컬 저장, JSON 백업·복원

공정 지식 바로가기: https://y2khoj.github.io/skct/hynix-interview/#/process

## 실행

빌드나 의존성 설치가 필요 없는 정적 HTML/CSS/JavaScript 앱입니다.

```sh
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. GitHub Pages 하위 경로에서도 동작하도록 상대 경로와 해시 라우팅을 사용합니다.

## 콘텐츠 검증

```sh
node verify-content.mjs
node --check assets/app.js
```

## 데이터와 출처

개인 답변·진도·성과 근거는 `localStorage`의 `hynix-interview-lab-v1`에 저장됩니다. 서버 전송이나 기기 간 자동 동기화는 없습니다. 브라우저를 바꾸기 전 복습 노트에서 백업 파일을 내보내세요. 백업을 불러오면 현재 기록을 교체합니다.

지원서 PDF 원본, 이름, 연락처, 주소는 포함하지 않습니다. 경력 기반 질문에서 확인되지 않은 모델·계수·시험 조건은 사용자가 직접 작성하도록 구성했습니다. 실제 수행 경험과 새로 주어진 가정 상황을 구분합니다.

PackagingBook의 교육 콘텐츠를 참고·각색한 단원과 면접 문제에는 저작자·원문·CC BY 4.0 및 변경 범위를 표시합니다. [ATTRIBUTION.md](./ATTRIBUTION.md)를 참조하세요. 공정 교재 확인일은 2026-10-24이며 산업 자료 기준일과 구분합니다.

학습 단원과 산업 카드에는 공식 기술 자료·발표의 링크를 제공합니다. 제품 상태는 발표·샘플·데모·양산을 구분하며, 시나리오와 직무 관점은 해석으로 표시합니다. 면접 전 최신 발표를 확인하세요.

이 프로젝트는 개인 학습용이며 SK하이닉스의 공식 채용 서비스가 아닙니다.
