# 학습 구조 재검토 · 최종 개정

2026-10-18. 사용자의 요청에 따라 학습 설계·기술 정확성·면접 깊이·사용성 관점의 독립 검토와 상호 반론을 진행했다. 아래는 채택한 결론과 실제 반영 내용이다.

## 무엇이 부족했나

- 개념 설명, 면접 질문, 성과 근거 카드가 연결되어 있지만, 질문에 답할 사고 과정을 배우는 완결 풀이가 부족했다.
- 어려운 질문의 수가 많아도 숫자·조건을 바꾸어 판단하는 연습이 없으면 학습 깊이를 보장하지 못했다.
- 읽기 완료, 단일 개념 퀴즈 정답, 답변 검토를 준비도처럼 혼용했고, 평가하지 않은 0점과 실제 0점을 구분하지 않았다.
- NAND 단원에 DRAM 그림을 재사용했고, CCSB·HBM의 핵심 구조를 보여 주는 도식이 부족했다.
- 추가 질문 A/B가 서로 다른 반문인데도 같은 검토 기준을 반복했다. 모바일에서는 학습 목표와 목차가 긴 본문 뒤에 있었다.

| 추가 질문 | 모든 분기를 순서대로 통과 | L1–L5는 탐색 가능한 단계로 두고, A/B는 답변의 특정 주장에 따라 선택한다. 분기별 가설·검토 기준·보완 방향을 다르게 제공한다. |

## 여섯 핵심 사례

1. **C1 Warpage:** Δα·ΔT·L로 구한 24μm는 자유 열팽창 차이이며, 실제 휨 값이 아니다. 구속·적층·물성·이력이 추가로 필요하다.
2. **C2 CCSB:** 강체 코어 200μm가 190±3μm 간격에 들어갈 수 없는 조건과, 230μm 간격에서도 젖음·접촉을 보장하지 못하는 이유를 나눈다.
3. **C3 BLR:** 학습용 수명식에서 손상 20% 감소는 약 1.40배 수명비다. 독립 입력 불확실성에 따라 설계 순위가 뒤집힐 수 있다.
4. **C4 Submodel:** 메시 수렴, 절단 경계 민감도, 시간증분 및 실험 타당성 검증을 서로 구분한다.
5. **C5 Bandwidth:** 이론 1,024GB/s와 지속 800GB/s를 구분하고 연산 강도 20FLOP/B에서 16TFLOP/s Roofline 상한을 계산한다. 상한이 실제 성능이나 포화 진단을 뜻하지 않는다.
6. **C6 Regression:** 5변수 완전 2차 모형의 21계수를 20관측만으로 유일하게 추정할 수 없는 문제와, 규제화·독립 검증·누수·외삽을 구분한다.

## 구현 후 교차 검토에서 바로잡은 오류

- T4의 실제 A/B 질문과 코칭의 상황이 달랐다. 위치별 코어 크기의 제조 공차·원가와 보드볼 경험의 HBM 전이에 맞추어 코칭을 다시 작성했다.
- 경험 경로의 C3 설명이 사례에 없는 상관관계 계산을 약속했다. 실제 사례인 비선형 수명비와 순위 불확실성에 맞추었다.
- M5 퀴즈가 본문 계산을 그대로 반복했다. 2,048bit × 6Gbit/s 조건으로 바꾸고 잘못된 단위, DDR 중복, 응용 성능 보장 오류를 각각 설명했다.
- 기존 파일 순서의 다음 단원 링크와 새 학습 경로가 충돌하지 않도록, 권장 다음 활동으로 통일했다.
- 추가 브라우저 검사에서 사례 태그의 Roofline이 검색되지 않았다. 사례 ID·태그·풀이 본문도 검색 대상으로 포함하고 모바일 메뉴와 검색을 다시 확인했다.

## 검증 범위

`node verify-content.mjs`는 18개 단원, 70개 질문, 6개 사례, 두 경로, 10개 코칭, 자료 참조, 분기 기준, 핵심 산술을 검사한다. 실제 Chromium 검증 결과: 101개 데스크톱 경로의 렌더링, 6개 사례의 모든 선택지별 해설·두 관측 분기·저장 후 재로딩, H1 메모, 근거 카드 앵커, 명시적 0점, 기존 기록 이관, JSON 백업·복원이 통과했다. 360·390·768·1024px 화면에서 주요 경로의 페이지 가로 넘침이 없었으며 JavaScript 실행 오류는 0건이었다.

산업 자료 확인 기준은 **2026-10-17**을 유지한다. 발표·샘플·시연·출하를 구별하고 공식 원문과 조건부 전망을 함께 제공한다. 실제 지원서 원본이나 연락처는 배포하지 않는다.

## 배포본 재점검 · 2026-10-18

페이지 렌더링 확인을 넘어 실제 학습 순서를 따라가며 다음 문제를 재현하고 수정했다.

| 발견한 문제 | 재현과 영향 | 수정 |
| --- | --- | --- |
| 선택한 학습 경로 이탈 | 구조 경로는 M1 다음 P1을 안내하지만 M1의 이어가기는 M3으로 이동했다. 경험 경로에서도 사례의 일반 연결이 선택한 순서와 달랐다. | 경로에서 시작한 활동에 경로 맥락을 유지하고 이전·다음 단계 및 경로 복귀를 제공한다. 경로를 벗어나 자유 학습으로 전환할 수 있다. 근거 카드의 다음 단계는 해당 카드 안에도 배치했다. |
| 답변 수정 뒤 이전 평가 유지 | 답변을 전면 수정해도 기존 10/10과 자가검토 집계가 유지됐다. | 본문을 바꾸면 기존 평가 선택을 해제하고 재검토 필요 상태로 표시한다. 명시적 0점은 평가로 인정하며 다시 다섯 항목을 평가하면 집계에 반영한다. |
| 같은 모바일 메뉴 재선택 | 현재 보고 있는 메뉴를 다시 누르면 해시 변경이 없어 서랍과 본문 비활성 상태가 남았다. | 모바일 메뉴 링크 클릭 시 이동 여부와 무관하게 서랍을 닫고 본문 조작을 복구한다. |
| 일부 질문의 필수 원리 해설 부족 | T1-L2 구성방정식, T4-L2 젖음 에너지·하중 제어, T9-L1 열전달 물리량, T9-L2 벽면 처리의 설명이 질문 수준에 비해 부족했다. | 네 단계에 정의·수식·가정·가상 계산·적용 한계·직접 출처를 추가했다. 실제 수행 모델과 혼동하지 않도록 표시했다. |
| 방법론 출처 추적 부족 | P6 박리와 P7 서브모델링 단원의 출처는 주로 패키징 구조 소개였다. | Cohesive와 submodeling의 가정·손상·경계 전달을 설명하는 Abaqus·Ansys 기술 문서를 직접 연결했다. |

산업 카드 6건은 공식 원문을 다시 대조했다. 발표일과 샘플·양산·출하·향후 계획의 구분에서 불일치를 발견하지 못했다. 기존 출처 23개의 본문을 확인했으며, Surface Evolver는 일반 HTTP 요청의 406 응답과 달리 실제 브라우저에서 200으로 열렸다.

수정 후 두 학습 경로를 처음부터 마지막까지 실제 링크로 이동하고 각 단계에서 새로고침해 맥락 유지를 확인했다. 답변 수정→재검토→명시적 0점→집계, 같은 모바일 메뉴 재선택, 경로·평가의 백업 복원을 검증했다. 기존 101개 경로, 6개 사례의 선택지·분기·저장, H1 메모, 기록 이관을 다시 확인했고 360·390·768·1024px의 주요 화면에서 가로 넘침이 없었다. 새 원리 해설 네 개의 렌더링·수식·모바일 읽기·검색과 예제 산술도 통과했다.

지원서의 ‘80% 정합성’ 정의, 실제 재료·수명 모델·계수 및 시험 조건은 웹 자료로 확인할 수 없으므로 사용자가 작성하는 근거 카드로 유지한다. 이 검토가 실제 면접 결과나 사내 비공개 공정 조건을 검증하는 것은 아니다.
