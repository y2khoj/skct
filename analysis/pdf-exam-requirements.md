# SKCT PDF 시험 웹앱 요구사항

작성일: 2026-10-03

이 문서는 인터뷰에서 합의한 요구사항과 구현 제안을 구분한다. 기존 앱의 시험 화면을 바탕으로 별도 웹앱을 만들기 위한 설계 기준이며, 구현 완료를 의미하지 않는다.

## 목적과 범위

- 사용자가 자신의 PDF로 실제 시험처럼 SKCT 문제를 풀 수 있는 공개 웹앱.
- 시험 화면과 PDF 가져오기, 시험 구성, 채점 및 간단한 오답 기록에 집중한다.
- 기존 앱의 계산기, 메모장, 그림판과 시험 화면을 재사용할 기반으로 삼는다.
- 운영자와 사용자에게 유료 OCR/API 이용료가 발생하는 방식은 사용하지 않는다.
- 초기 시험 대상은 SKCT이며, 여러 출판사의 텍스트 PDF와 스캔 PDF를 대상으로 한다.
- 사용자별 PDF를 불러오는 방식으로 구성한다.

## PDF와 문제 표시

- 문제 번호를 기준으로 문제를 자동 분리한다.
- 원본의 그림, 표, 수식과 보기를 보존하여 표시한다.
- 보기 위치를 인식하여 원본 문제 위에서 답을 선택할 수 있게 한다.
- 다음 페이지로 이어지는 내용은 해당 문제에 합친다.
- 일반 문제는 한 문제씩 표시한다.
- 공통 지문을 공유하는 문제는 앞선 인터뷰에서 선택한 묶음 표시를 유지한다. 마지막 답변의 '한 문제씩'은 전체 페이지를 대신 보여주는 처리에 대한 거부로 해석한다.
- 인식 실패 시 전체 PDF 페이지로 대체하거나 원본 밖의 별도 보기 버튼으로 우회하는 방식은 채택하지 않는다.
- OCR 글자 수정, 영역 조절, 문제 합치기·나누기 편집기는 초기 범위에 포함하지 않는다.
- 정답과 해설은 PDF에서 추출한다. 추출한 정답·해설은 사용자가 수정할 수 있다.

## 시험 준비

1. 사용자가 자신의 PDF를 불러온다.
2. 회차, 영역, 문제 번호를 자동으로 찾는다.
3. 시작 전에 인식된 회차·영역 목록을 확인한다.
4. 회차·영역을 찾지 못한 경우 사용자가 해당 페이지 범위를 지정한다. 이는 개별 문제 영역 편집과 구분한다.
5. 사용자가 출제할 문제와 회차 순서를 선택한다.
6. 첫 영역의 문제 표시와 답 선택에 필요한 준비를 마친 뒤 시험과 타이머를 시작한다.

여러 회차를 한 번에 불러와 선택한 순서대로 진행할 수 있어야 한다. 처음 분석한 결과는 재사용할 수 있게 한다. 최초 요청의 '첫 두 문제 약 3초'는 희망 성능이며 보장된 수치가 아니다. 후속 답변에 따라 첫 영역 준비 후 타이머를 시작하는 정책을 우선한다.

## 시험 진행

- 영역별 제한 시간은 15분이며, 5영역 기준 총 배정 시간은 75분이다.
- 이전 문제로 돌아갈 수 없고 다음 문제로만 이동한다.
- 다음 문제로 이동할 때 돌아올 수 없다는 확인 알림을 제공한다. 미응답인 경우 답을 선택하지 않았다는 사실도 표시한다.
- 확인 알림에서 취소하면 현재 문제에 남고, 진행하면 답안을 확정하고 다음 문제로 이동한다.
- 공통 지문 문제 묶음은 묶음을 떠날 때 해당 묶음의 답안을 확정한다.
- 영역의 15분이 끝나면 해당 영역을 마감하고 다음 영역을 자동으로 시작한다.
- 사용자가 영역을 일찍 마쳤다면 다음 영역을 즉시 시작할 수 있다. 남은 시간을 다음 영역에 더하지 않는다.
- 선택한 여러 회차는 순서대로 진행한다.
- 계산기, 메모장, 그림판을 제공한다.

## PC 저장과 복습

- PC 저장은 사용자에게 선택 옵션으로 제공한다.
- 오답 기록은 문제 번호를 중심으로 구성한다. 다른 PDF·회차·영역의 같은 번호를 구분할 수 있는 식별 정보가 함께 필요하다.
- 정답 추출 결과와 사용자의 정답 수정 사항도 재사용 가능하도록 설계한다.
- 저장을 선택하지 않아도 현재 세션에서 시험을 치를 수 있는 구성을 권장한다.

저장 방식의 구현 제안: PDF와 분석 결과를 다시 불러올 수 있는 로컬 파일로 내보내고 가져오는 기능을 제공한다. 브라우저 내부 저장과 사용자가 다운로드한 파일은 서로 다른 저장 방식이므로 UI에서 구분한다. 저장 파일에 원본 PDF를 포함할지, 분석 정보만 포함하고 원본은 다시 선택할지는 구현 설계에서 구체화한다.

## 기술 방향과 검증 과제

아래 항목은 사용자 확정 요구를 만족하기 위한 구현 제안이다.

- PDF 처리와 OCR을 사용자 브라우저에서 실행하여 유료 처리 API 의존성을 없앤다.
- 텍스트와 위치 정보가 있는 PDF는 이를 우선 활용하고, 스캔 페이지에는 OCR을 적용한다.
- 원본 이미지 위의 보기 선택 영역은 확대·축소 시에도 원본 보기와 일치해야 한다.
- 첫 영역을 준비한 뒤 나머지 영역을 처리하는 경우에도 시험 중 인식 대기로 시간이 소모되지 않도록 준비 정책을 검증한다. 필요하면 선택한 회차 전체를 준비한 후 시작한다.
- 무료 배포 서비스의 조건과 용량 제한은 실제 배포처를 정할 때 확인한다.
- 출판사별 문제 번호, 두 단 배치, 페이지를 넘는 문제, 공통 지문 및 보기 위치 인식 정확도를 실제 자료로 검증한다.
- 인식 실패 처리 제안: 자동 재시도 후에도 문제 경계나 보기 위치를 확정하지 못하면 해당 문항을 명시하고 선택한 시험의 시작을 보류한다. 문제를 조용히 누락하거나 페이지 전체로 대체하지 않는다. 수동 영역 편집 없이 모든 PDF를 지원할 수 있다고 보장하지 않는다.

## 완료 판단 기준

- 사용자가 PDF를 불러와 회차·영역·문제를 선택하고 시험을 시작할 수 있다.
- 원본 문제와 보기를 보존하면서 보기 위치에서 답을 선택할 수 있다.
- 일반 문제 단위 표시, 페이지 연결 및 공통 지문 묶음이 실제 자료에서 동작한다.
- 다음 이동의 확인 알림, 이전 이동 금지, 영역별 마감 및 다음 영역 자동 시작이 동작한다.
- 계산기·메모장·그림판이 시험 화면에서 동작한다.
- PDF에서 추출한 정답·해설을 수정하고 채점에 반영할 수 있다.
- PC 저장을 선택하여 분석 결과와 오답 문제 식별 정보를 다시 사용할 수 있다.
- 유료 OCR/API 없이 동작한다.
