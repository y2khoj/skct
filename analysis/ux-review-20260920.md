## 실제 검증

- Node 기존 회귀 테스트 13개: 모두 통과.
- 전체 문항 렌더링: 299개, 오류 0개.
- 브라우저: 1280×900, 390×844, 360×800에서 확인.
- 훈련 시작 → Space로 보기 선택 → 제출 확인 → 채점 → 해설 열기 확인.
- 풀이 도구 및 답안 패널: 열기, Escape 닫기, 트리거로 초점 복귀 확인.
- 확인 대화상자: 마지막 버튼의 Tab이 첫 버튼으로 순환하는지 확인.
- 모의고사 보기 취소 후 선택 수 0, 답안 현황 미응답 복귀 확인.
- 계산연습 Enter 중복 이동 방지 확인.
- 테스트는 localhost 브라우저에서 수행. 실제 사이트의 학습 기록을 조작하지 않음.

## 유지보수 지침

- 색상 토큰은 style.css, CI 표현은 hynix-theme.css, 사용성/반응형 규칙은 usability.css에 둔다.
- 풀이 도구·대화상자 공통 동작은 ui-shell.js, 본문 렌더링·글자 확대는 question-text.js에서 관리한다.
- 답 선택 및 취소는 각 앱의 기존 답안 저장 함수를 호출한다. 문제 데이터와 정답 ID는 변경하지 않는다.
- DOM 기반 초점 관리와 CSS 반응형 화면을 검증한 범위이며, 실제 보조기기 전체 조합을 인증한 결과는 아니다.
