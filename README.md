# SKCT 나의 훈련실

공유 대화의 **유형 진단 → 15분 집중 → 5영역 연속 → 약점 복습** 흐름으로 연습하는 웹앱입니다.

## 내 PDF 실전 시험

별도 [PDF 시험 웹앱](pdf-exam/)에서 각자 가지고 있는 SKCT PDF를 불러와 문제를 풀 수 있습니다. 문제·정답 PDF 분석과 OCR은 브라우저에서 실행하며, PDF 암호는 저장하지 않습니다. 여러 PDF의 회차·영역·문제를 선택하고 원본 보기 위에서 답을 표시할 수 있습니다. 영역별 15분, 다음 문제로만 이동, 계산기·메모장·그림판, 정답 수정과 오답 번호 저장을 지원합니다.

GitHub Pages 주소는 [내 PDF로 보는 SKCT 실전 시험](https://y2khoj.github.io/skct/pdf-exam/)입니다. PC 저장 옵션을 선택하면 브라우저에 PDF와 분석 결과, 오답 번호를 보관합니다. 별도 분석 파일로 내보내거나 가져올 수도 있습니다. 자동 인식이 불완전한 문제는 준비 화면에 표시되며, 보기를 모두 찾지 못한 문항은 시험에 넣을 수 없습니다. PDF 형식에 따라 인식 결과를 확인해 주세요.

## 텍스트 문제 은행 (2026-09-20)

문제 화면과 정답 화면은 299개 개별 문항의 텍스트 데이터를 사용합니다. 보기 문장을 누르면 기존 OMR과 같은 문항 ID로 답안이 저장됩니다. 정답 문장과 채점 번호는 `answer_option_id`가 가리키는 보기에서 함께 가져옵니다. 기존 학습 기록 ID와 페이지 단위 출제는 유지합니다.

- `data/question-bank.json`: 문제·보기·정답 연결의 편집 기준 파일
- `data/question-bank.md`: 읽기용 문제·정답 전체 목록
- `data/question-bank.js`: 브라우저에서 사용하는 빌드 결과
- `data/text-overrides.json`: 원본 재추출 시 적용할 전사 보정
- `analysis/authoring-guide.md`: 유형 분석, 출제 구조, 원본 오류 및 다음 검증 항목

변경 후 `node build-question-bank.cjs`를 실행하면 JS와 읽기용 목록이 갱신됩니다. `extract_question_bank.py`는 원본 재추출용으로, 직접 수정한 JSON을 덮어쓰므로 평소 편집 후에는 실행하지 않습니다.

표·분수·도형은 실제 텍스트와 배치를 보존합니다. 그림이 필요한 지도·산점도 등은 그림과 설명을 함께 표시합니다. 원본 문제·해설은 접힌 참고 항목으로 열 수 있습니다. 공통 지문은 해당 문항에 자동으로 함께 표시됩니다. 자료해석 30번에서 누락되었던 다음 페이지의 보기 5개도 복원했습니다.

검증: `node --test training-core.test.cjs data-mapping.test.cjs question-bank.test.cjs`. 브라우저 전체 렌더링 검사는 `text-render.test.html`에서 실행됩니다. 현재 299문항 렌더링 오류 0개, 자동 테스트 13개 통과입니다. 정답의 원본 대조와 모든 문제의 독립 재풀이 검증은 구분하며, 출제 전 추가 검증 기준은 분석 문서에 있습니다.

## 실행

`실행하기.bat`을 더블클릭하면 `http://localhost:8085`에서 열립니다. Python이 설치되어 있어야 합니다. 서버 없이 `index.html`을 직접 열어도 풀이가 가능합니다. 기록은 브라우저와 주소별로 따로 저장되므로 같은 주소를 사용하세요.

웹에서는 [SKCT 나의 훈련실](https://y2khoj.github.io/skct/)을 이용하세요. `main` 브랜치에 변경을 올리면 기존 GitHub Pages 설정으로 배포됩니다. 웹 주소와 로컬 주소의 훈련 기록은 별도로 저장됩니다.

## 훈련 순서

1. **유형 진단**: 자료해석 10문항부터 시간 제한 없이 풉니다. 문항별 시간은 기록됩니다. 언어추리도 같은 방법으로 진단하세요.
2. **15분 집중**: 기본 20문항 / 15분입니다. 15초가 지나도록 방향이 안 보이면 `보류하고 다음`을 누릅니다. 쉬운 문제를 푼 뒤 `보류 회수`로 돌아옵니다.
3. **5영역 연속**: 언어이해 → 자료해석 → 계산연습 → 언어추리 → 수열추리 순서입니다. 제출 또는 시간 종료 뒤 결과를 확인하고 `다음 영역 시작`으로 넘어갑니다. 영역마다 독립된 제한 시간을 사용합니다.
4. **약점 복습**: 오답, 미응답, 45초 초과, 검토 표시 문항을 새 답안으로 풉니다. 제출한 뒤 오답 원인과 다음에 바꿀 행동을 기록합니다.

문항마다 상단의 `이 문제 00:00`에 풀이시간이 표시됩니다. 문제 이동 시 해당 문항의 시간 기록이 멈추고, 다시 돌아오면 이어서 누적됩니다. 제출 결과에서 개별 시간을 확인하고 45초 초과 문항만 모아볼 수 있습니다.

풀이 중 `1~5`는 답 마킹, `←/→`는 이동, `S`는 보류, `Esc`는 일시정지입니다. 입력란에서는 단축키가 작동하지 않습니다. 일시정지 시 문제를 가립니다.

계산기는 기본적으로 꺼져 있습니다. 설정에서 켜면 숫자패드를 사용할 수 있습니다. 계산기 버튼에 포커스가 있을 때는 일반 숫자 키도 계산기로 들어갑니다. 메모 입력 중에는 숫자패드도 메모에 입력됩니다. 계산기는 입력한 연산 순서대로 계산합니다.

## 결과와 저장

- 객관식 완료율, 정답·오답·미응답, 응답 문항의 정답률
- 문항별 누적 시간, 45초 초과, 보류 후 정답 회수 수
- 원인 분류와 다음 풀이 행동, 최근 회차 다시 보기
- 답안·메모·현재 위치·남은 시간 자동 저장 및 이어하기
- JSON 기록 백업 / 가져오기

시간은 시작한 동안 누적되며 일시정지·훈련실 화면·브라우저 종료 중에는 늘어나지 않습니다. 새로고침 후 이어하기로 재개합니다. 백그라운드 탭의 타이머 지연을 보정하기 위해 실제 경과 시간을 사용합니다. 백업 가져오기는 기존 훈련 기록을 대체합니다.

첫 앱의 `skct_answers`, `skct_q_memos` 등 기존 저장 키는 변경하지 않습니다. 새 기록은 `skct_training_v2`에 저장됩니다. 이전 답안을 새 회차에 자동으로 채우지 않습니다.

## 자료의 범위

기존 문제 이미지와 해설을 사용합니다. **객관식 214문항 + 수동 점검 85문항**이며 총 299문항 / 168페이지입니다.

| 영역 | 자료 |
| --- | --- |
| 언어이해 | 48문항 |
| 자료해석 | 30문항 |
| 언어추리 | 96문항 |
| 수열추리 | 40문항 |
| 응용수리 / 경우의 수 | 85문항 (28페이지) |

계산연습은 여러 문제가 포함된 페이지이며 개별 정답은 원본 정답표와 연결되어 있습니다. 훈련 화면에서는 수동 점검 방식으로 유지하여 객관식 채점과 45초 지표에서 제외합니다. 풀이 답안을 적고 제출한 뒤 해설을 대조하여 `해설 대조 완료` 또는 `다시 연습`을 표시하세요.

자료보다 많이 요청하면 보유한 만큼만 출제하며 회차 안에서 중복 출제하지 않습니다. 덜 풀어본 문항을 우선 선정합니다. 여러 문항을 담은 페이지 단위로 출제하므로 실제 시험의 개별 문항 구성과 다릅니다. 실제 시간·문항 수·도구 허용 여부는 본인 응시 안내를 기준으로 설정하세요.

### 문제·정답·해설 매칭 검증 (2026-09-15)

원본 PDF의 299개 개별 문항 정답을 정답표와 대조했습니다. 정답 번호는 모두 일치했고, 잘못 연결되거나 일부 해설이 누락된 이미지 101개를 재생성했습니다. 35개 문제 페이지에는 해당 문항의 해설 페이지를 모두 이어서 표시합니다. 경우의 수 해설은 손글씨 원본의 문항 번호를 확인해 연결을 수정했습니다.

현재 자료는 언어이해 48문항, 자료해석 30문항, 언어추리 96문항, 수열추리 40문항, 응용수리·경우의 수 85문항으로 총 299문항 / 168페이지입니다. 응용수리 훈련은 여전히 수동 점검 방식입니다.

`data/skct_data.json`은 원본 페이지·해설 연결의 기준 데이터이며 JS 파일도 동일한 내용입니다. 현재 화면의 문제 텍스트와 정답 보기 연결은 위의 `question-bank.json`을 우선 사용합니다. 각 문항에는 정답표 PDF 페이지와 해설 PDF 페이지를 기록합니다. 원본 출판물 자체의 정답 타당성을 독립적으로 재풀이한 검증은 아닙니다.

- 회귀 검사: `node --test training-core.test.cjs data-mapping.test.cjs`
- 원본 대조: `SKCT_PDF_PASSWORD` 환경변수를 설정한 뒤 `python verify_mapping.py` (PyMuPDF, Pillow 필요)
- 데이터·이미지 재생성: `python generate_perfect_skct_data.py`

검증 스크립트는 문제 번호, 정답표, JS/JSON 일치 여부, 전체 문제·해설 이미지의 픽셀 일치 여부를 검사합니다. 원본 PDF는 저장소에 포함하지 않습니다.

## 계산 워밍업

증가율, 구성비, 비율 비교, 평균, 역산을 5문제로 연습합니다. 계산기 없이 답을 근사한 후 식과 비교합니다. 증가율·구성비는 ±1%p, 평균·역산은 ±2%를 성공 범위로 사용합니다. 워밍업 결과는 본 문제의 정답률에 합산하지 않습니다.

## 파일과 검증

- `index.html`: 기존 문제풀이 화면
- `training.js`, `training.css`: 시작 화면, 진행, 복습, 기록, 워밍업
- `training-core.js`: 출제·채점·복습 선정 규칙
- `app.js`: `exam.html`의 시험 화면 엔진

검증 명령: `node --test training-core.test.cjs`

브라우저에서 진단 시작, 보류·회수, 답안 및 메모 복구, 제출 후 답안 잠금, 원인 저장, 독립된 복습 회차, 영역 전환, 시간 종료 자동 제출, 5영역 완료, 계산연습 수동 점검, 계산 워밍업을 확인했습니다.
