# SKCT 온라인 실전 문제풀이 및 자동 채점 웹앱

> SK Competency Test (SKCT) 유형별 문제풀이, 자동 채점, 메모장, 전용 계산기 지원 웹 애플리케이션  
> **라이브 웹사이트**: [https://y2khoj.github.io/skct/](https://y2khoj.github.io/skct/)

---

## 🖥️ 주요 기능

- **화면 3/4 (가로 75%) 문제 영역**: 1화면 1문제 표시, 150 DPI 고해상도 렌더링, 답안 마킹 OMR 및 키보드 단축키 지원
- **화면 1/4 (가로 25%) 사이드 패널**:
  - **상단 50% 메모장**: 문제별 자동 분리 저장 메모 및 공통 연습장
  - **하단 50% 계산기**: 숫자패드(Numpad) 및 수식(`+`, `-`, `*`, `/`, `Enter`) 완벽 연동, 계산 기록 테이프
- **실시간 저장 (Persistence)**: 선택 답안, 메모, 검토 플래그를 `localStorage`에 자동 보존
- **자동 채점 및 오답노트**: 제출 즉시 성적 리포트, 정답률, 오답 필터링 및 원본 상세 해설 확인 기능

---

## 📚 수록 과목 (총 168문항)

- **언어이해**: 48문항 (출제예상 20문항 + PSAT기출 28문항)
- **자료해석**: 30문항 (통계표/그래프 분석)
- **언어추리**: 48문항 (명제추리 + 조건퀴즈 + 실전모의)
- **수열추리**: 14문항 (수열 및 도형 규칙)
- **응용수리/경우의수**: 28페이지 (소금물, 거속시, 순열/조합 등)
